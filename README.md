# 言い訳寺（いわけでら）

> 大仏が、あなたの言い訳をお聴きになる。（どこの大仏かは聞かないでいただきたい）

世界中のTODOアプリは「やる気」を要求してきます。
当寺の大仏はやる気を要求しません。ただ聴き、裁き、そして**2分だけ**動かします。

## 何ができるのか

| お悩み | 当寺のご利益 |
| --- | --- |
| 言い訳が止まらない | 大仏が「言い訳芸術点」として採点（辛口だが根は慈悲） |
| 何から手をつけていいか分からない | 「仏の一手」：最初の2分間でやることを具体的にご下賜 |
| やる気が出ない | 2分間の修行タイマー（木魚の音付き。やる気は不要） |
| イライラする | 木魚ボタン。叩くたび功徳。叩くだけで心が澄む（当寺調べ） |
| 心が荒んでいる | 今日の御詠歌。言い訳を詠んだ歌をご用意 |

## 使い方

1. 告白の間に、正直に言い訳を書く
2. 「告白する」を押す
3. 大仏の裁定が下る（言い訳芸術点 + 説法 + 最初の2分間の行動）
4. 「よし、2分だけやる」を押して修行を開始
5. 終わったら終了の鐘が鳴る。やめたくなったら「やっぱりやめる（仏もたまには休む）」も認められている

功徳を積むと段位が上がります：童子 → 沙弥 → 行者 → 和尚 → 座主 → **大仏**（もはや言い訳は慈悲）。

## 技術

- HTML / CSS / バニラJS 1本。ビルド不要。フレームワーク不要。仏の教え通り、シンプルである。
- 木魚と鐘はWeb Audio APIでその場で合成。音源ファイルすら仏に預けていません。
- 功徳はどこにも保存せず、サーバーにも何も送らない。ブラウザを閉じれば仏も忘れる。それでいい。諸行無常である。

## 開発

```bash
# ローカルで開くだけ。npm install する場所は仏の前にはありません。
open index.html
```

- 言い訳芸術点が高評価でも、締め切りは延期されません。仏の裁量の範囲外です。
